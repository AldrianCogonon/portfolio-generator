# IMPORTANT NOTE
Don't push to main/master. Create your own branch and create a pull request to avoid breaking the project.

# How to setup
- step 1: Download the LTS installer from the official `Node.js website`
- step 2: Run the installer and click through the setup (leave everything as default)
- step 3: Opeen Command Prompt or PowerShell and verify it installed correctly by running:
`node -v`
`npm -v`
**(If it shows version numbers, you are ready to go)**
- step 4: Open vscode
- step 5: type in terminal `git clone https://github.com/AldrianCogonon/portfolio-generator.git` 
- step 6: Go to **File > Open Folder...** and select the cloned folder.
